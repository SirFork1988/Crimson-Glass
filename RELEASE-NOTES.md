Crimson Glass 1.0.0 brings the complete black-and-red glass theme to KDE Plasma 6.

Download **Crimson-Glass-1.0.0.zip** below; the automatic GitHub source archives do not contain the theme asset bundle. Extract the installer ZIP and run `sh ./install.sh --all` as your normal desktop user. Log out and back in afterward.

The installer downloads native prerequisites, saves a backup, and applies the corrected icon pack, Kvantum/Qt and GTK styles, Andromeda launcher, global menu, floating dock, monitoring widgets, and matching startup screens. `--no-layout` preserves existing panels/widgets; omit `--all` for desktop only.

Requires KDE Plasma 6. The README inside the ZIP documents supported distro recipes, SDDM/Plymouth requirements, bootloader splash configuration, and restore commands. Live installations on other distributions remain untested; installation/restore simulations pass.

Verify the download using the attached `.sha256` file: `sha256sum -c Crimson-Glass-1.0.0.zip.sha256`.
