# Crimson Glass app icon artwork

The faceted plates and subject glyphs were created for the Crimson Glass KDE setup.
This layer is distributed under GPL-3.0-or-later. The original app identifiers are
used solely for desktop icon lookup. It is an unofficial customization.

Microsoft Edge, Firefox, Zen Browser and Steam glyph geometry is adapted from
the installed [Papirus icon theme](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme).
Papirus is GPL-3.0 licensed. Existing rounded/circular icon backplates were discarded;
the surviving vector geometry was recolored in Crimson Glass colors and mounted on
new original faceted plates. Trademarks remain the property of their respective owners.

The ChatGPT icon is a new chat/hexagon design, not the official OpenAI knot logo.
Teams, Home Assistant and Music Assistant icons are new subject-based vector glyphs.

All SVGs are self-contained: no scripts, fonts, raster images, remote resources or
external references are used. The manifest records exact upstream files and aliases.
