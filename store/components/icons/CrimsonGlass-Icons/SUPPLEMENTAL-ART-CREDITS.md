# Crimson Glass supplemental icons

Ten original subject glyphs use the original faceted charcoal/ruby plate from
`work/build_crimson_custom_icons.py`. Both the plate and this supplemental layer
were created for the Crimson Glass KDE setup. License: GPL-3.0-or-later.

App identifiers are used only for desktop icon lookup. These are unofficial
customizations and do not use copied application logo geometry. The SVGs contain
no raster images, scripts, fonts, remote resources, or external references.

The manifest records aliases and exact audited desktop entries. Entries with
absolute icon paths or missing Icon keys need a local desktop entry override;
installing a theme alias alone cannot change those launcher icons.
