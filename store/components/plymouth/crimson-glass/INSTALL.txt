Crimson Glass Boot Splash 1.1.0

Requires Plymouth's two-step renderer and Noto Sans/Noto Sans Light/Noto Sans Mono. Install crimson-glass into /usr/share/plymouth/themes using your distribution's theme manager, select it and rebuild the initramfs using your distribution's documented procedure. This archive contains no bootloader, initramfs, or privilege scripts.

Project: https://github.com/SirFork1988/Crimson-Glass
Full installer and optional runtime: https://github.com/SirFork1988/Crimson-Glass/releases/tag/v1.1.0
This native component contains no automatic installer or post-install hooks.
