Crimson Glass Login 1.1.0

Requires SDDM with Qt 6, Plasma 6 Breeze components, Kirigami, Plasma Components, and Qt5Compat GraphicalEffects. Install via System Settings > Login Screen (SDDM) > Install from File, then select Crimson Glass. Administrator authentication is required. This archive never changes the display manager automatically.

Project: https://github.com/SirFork1988/Crimson-Glass
Full installer and optional runtime: https://github.com/SirFork1988/Crimson-Glass/releases/tag/v1.1.0
This native component contains no automatic installer or post-install hooks.
