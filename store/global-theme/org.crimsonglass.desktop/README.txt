Crimson Glass — Native Plasma 6 Global Theme
Version 1.1.0
https://github.com/SirFork1988/Crimson-Glass

Apply this package in System Settings > Colors & Themes > Global Theme.
It selects the crimson palette, Plasma style, complete icons, Aurorae window
borders, Qogir cursor and Crimson wallpaper, and includes the animated splash.
The native package uses the standard Breeze Qt widget style with our palette.

Optional desktop layout
Select the desktop-layout option in KDE's Global Theme application dialog
only if you want to replace your current panel/widget layout. This provides
a top global-menu bar, Andromeda launcher, centered floating dock and system
monitors. Global menus require applications that export a menu. If Andromeda
is unavailable, the layout uses KDE's Application Launcher. Monitor positions
are calculated for the current logical screen size. Very small workspaces
receive the panels only. System-monitor widgets require Plasma System Monitor.

Window transparency and the complete setup
For Qt widget glass, install Kvantum for each Qt version you use, then install
and select the matching CrimsonGlass style with Kvantum Manager. Choose
Kvantum in System Settings > Application Style. Our separate Kvantum component
also includes the Dolphin glass variant. The GTK theme is a separate component
and must be selected in the GTK application-style settings. Application-side
alpha, GTK4/libadwaita, Electron, Flatpak and Snap behavior can differ.

The native Global Theme does not install distro packages, Python services,
SDDM/Plymouth system files, fonts, or automatic display/game detection. The
GitHub full installer provides the complete 1.1.0 setup, including widget
realignment when displays change and opaque game windows. Follow its backup
and restore instructions. Screenshots show that complete installation;
install Kvantum and the other components to reproduce all of its details.
